### P0 成就+庆祝（服务游戏设计师）

### P1 兑现承诺（服务价值审查员）
- **拆解空话 → 方案 A 诚实删改**：删"帮你拆成不可能失败的小事"，改"带你从第 1 天里最小的一步开始，每天只多一点点"（与 CreateHabitForm 实际"从第1天做起/每天只多一点点"一致）。弃方案 B（需 NLP、易成"假装拆解"，正是价值审查员反感的言行不一）。
- **休息券差异化 → 核查确认已正确，无代码改动**：`scaleFlow.ts` 的 `actionRate` 用 `filter(!restDay)`——休息日排除行动率分母、最小版（保底）计入；HabitScreen 主卡+侧习惯的差异文案已明说（休息=完全放假保平均分 / 保底=免费但拉低行动率）；streakCoin 赠券反馈（连续达标7天获1券）已存在。

### P2 入口收敛（服务价值审查员）
- 8 平铺入口 → 4 组：一键达标（底部固定主 CTA）+ 打卡语（均零输入、醒目）；【多做了？】折叠（储蓄 1/2/5 + 精确输入）；【今天不想做？】折叠（休息用券 + 做 1 个就算数免券 + 差异说明）。
- 移除 HabitPanel 冗余"刚好达标"快速按钮（与主 CTA 重复）。**未丢任何功能**（休息/保底/储蓄/精确输入/打卡语全保留，仅重组布局）。
- 折叠默认收起，普通用户每日只见"一键达标 + 打卡语"。

## 决策要点
- **成就诚实**：只用真实计数，未达成不提前点亮，绝不编造。
- **拆解取舍**：宁承认"从最小一步开始"这个真做到的事，不空喊拆解（正是价值审查员最反感）。
- **入口不丢功能**：折叠藏低频出口，不藏每日主路径（零输入）。
- **P2 仅 UI**：habitFlow.ts / engine 未改，故无新增 flow 测试（项目无组件渲染测试 harness）。
- **拆分批派**：P0/P1/P2 三个独立 worker 批，先后完成，避免 R11 worker 单批过重卡死。
