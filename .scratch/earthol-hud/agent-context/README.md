## 评分演进（同一视角跨轮对比，衡量改造有效性）

| 第 30 天老用户 | 25-40 天卸载 | **7/10 · 再用 60 天**（上轮 5） | 清零死亡，但目标跳变还演 |
| 价值审查员 | 首漏卡即卸载 | **7/10 · 6-9 个月**（上轮 4-5） | 数据逃生+不惩罚兑现，拆解仍空 |

**观察**：全视角从"流失"转向"会继续用"，机制诚实度获全票。**共性剩余**：①成就/等级/庆祝反馈为零（游戏感只做一半）②拆解承诺未兑现 ③休息券相对保底仍是"废币" ④入口偏多。非致命但值得 R12。

**R12 处理**（见 `r12-engagement-round.md`）：①**成就+庆祝**落地（8 成就墙 + 打卡 toast）②**拆解承诺**诚实改说（弃假拆解）③**休息券**核查确认已正确（引擎已区分休息/保底差异）④**入口**收敛 8→4 组。334 测试全绿。**五视角期望收益留待四视角三查——评分填回下表（R12 三查列待填）。**
