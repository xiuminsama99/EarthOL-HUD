# 06: 一键打卡 + 天平可视化

**What to build:** 主界面收束为单一体验：底部一键打卡按钮（位于拇指最易触达处，一个按钮完成当日全部习惯）→ 打卡时强制一句话记录（「今天我以 XX 身份做了 XX」）→ 天平动画（左边真实自己、右边向往人生：打卡向右倾斜、漏卡向左倾斜）→ 累积数字增长与「已超过全球 X%」反馈 → 打卡历史可回看。（房间升级动画、宠物庆祝动画、AI 图均为后续迭代。）

**Blocked by:** 05（单个习惯的等差数列打卡）

**Status:** ready-for-agent

- [ ] 底部单一按钮一键完成当日全部习惯打卡，不做多种打卡入口
- [ ] 打卡必须附带一句话记录，无记录不能完成
- [ ] 打卡后天平向右倾斜、右边小人变亮开心、左边变暗
- [ ] 漏卡日天平向左倾斜、左边变亮、右边沮丧，弹「你离美好人生又远了一步」（不羞辱、不惩罚）
- [ ] 打卡后展示累计总量增长（如「今年已做 362 个」）与「已超过全球 X%」对比
- [ ] 主界面一眼可见四要素：左边真实的自己、右边向往的人生、中间宠物、底部一键打卡按钮
- [ ] 打卡历史可查看（日期、习惯、完成量、一句话记录）
