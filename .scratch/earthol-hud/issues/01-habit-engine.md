# 01: 微习惯引擎领域核心

**What to build:** 整个产品的领域大脑（唯一测试接缝），一个不依赖 UI、数据库、网络时间的纯逻辑模块。给引擎「习惯状态 + 当日日期与作息边界（注入参数）+ 当日完成量」，它返回当日目标量、超额警告、假期币、总量与习惯养成值、养成判定。所有时间输入由调用方注入，设备系统时间不参与判定。

**Blocked by:** None（可以立即开始）

**Status:** ready-for-agent

- [ ] 正向习惯按等差数列递增：第 N 天目标量 = 起始基准 + N，未锁死时每日只多做一个
- [ ] 反向习惯按等差数列递减：第 N 天目标量 = 起始基准 - N，每日只多减一点
- [ ] 用户设定自认上限后目标量锁死，后续天数不再变化
- [ ] 连续未打卡 N 天后重新归来，当日目标量从原位置回退 N 步，且永不越过起点（不退零）
- [ ] 单日完成量超出当日目标 → 产出「不建议，离目标更远」警告，超额量累计为假期币
- [ ] 假期币可抵扣休息日：抵扣日不计缺勤、不触发动态扣减
- [ ] 总量与习惯养成值分离：突击完成等差数列总和 → 总量计入、养成值不涨；每日持续执行 → 两者都涨
- [ ] 连续 21 天按等差数列执行 → 习惯标记为「已养成」；中途中断则养成计数重新开始（与总量无关）
- [ ] 打卡必须附带「今天我以 XX 身份做了 XX」的一句话记录，无记录的动作被拒绝
- [ ] 作息类型（白天工作 / 夜间工作）影响「今天」边界归属的纯函数判定（如夜间工作者凌晨打卡归昨日）
- [ ] 上述全部规则以注入式时间参数通过自动化测试（规则表测试，只断言输入输出，不测实现细节）

**验收说明:** 本工单只交付纯逻辑与测试，不包含任何 UI / 数据库 / 网络代码。完成后后续工单以黑盒方式调用引擎。
