# 04: 领养宠物并起名

**What to build:** 用户领养一只宠物作为情感锚点：选择品种（猫 / 狗 / 小恐龙等）、给它起名、宠物出现在主界面并展示基础形象。宠物档案（品种、名字）持久化，未领养的用户被引导到领养流程。（喂食/摸头互动、状态镜像、庆祝动画、桌面小组件均为后续迭代，不在本工单。）

**Blocked by:** 02（时间锚点 + 数据模型 + 登录地基）

**Status:** ready-for-agent

- [x] 用户可选择至少 3 种宠物品种（含猫、狗、小恐龙）
- [x] 用户可给宠物起名
- [x] 宠物档案（品种 + 名字）持久化，再次打开仍存在
- [x] 主界面展示宠物基础形象（静态形象即可）
- [x] 未领养宠物的用户被引导到领养流程

**扩展（超工单最小范围，产品体验所需）：** 心情值（0-100，初始 60）由打卡事件驱动（达标 +4 / 超额 +6 / 缺勤归来 -4 / 休息日 0，clamp 0-100），主界面宠物卡展示心情条与分段文案（元气满满 / 心情不错 / 一般般 / 有点低落）。喂食 / 摸头互动、状态镜像、庆祝动画、AI 形象均按工单定义后置。
