# 02: 时间锚点 + 数据模型 + 登录地基

**What to build:** 支撑所有链路的底座：服务端网络时间判定「今天」（改设备时间作弊无效）；BaaS 数据库表结构落地（用户、习惯、打卡记录、宠物、房间/资产、存钱账户、账单）；微信一键登录为主、手机号绑定备用；用户作息类型设置。技术栈：PWA 前端（可加主屏幕）+ BaaS（Supabase 或同类）+ 前端托管平台。

**Blocked by:** None（可以立即开始）

**Status:** ready-for-agent

- [ ] 用户可用微信一键登录（国内）或手机号绑定登录，登录状态持久化
- [ ] 「今天」的判定来自网络时间（服务端时间）而非设备系统时间
- [ ] 用户可设置作息类型（白天工作 / 夜间工作），当日边界计算正确（夜间工作者凌晨操作归属昨日）
- [ ] 数据模型在 BaaS 落地并可读写：用户、习惯、打卡记录、宠物、房间/资产、存钱账户、账单
- [ ] 前端 PWA 壳可安装/添加到主屏幕，与 BaaS 连通可完成一次完整登录与数据读写
- [ ] 网络时间边界判定的自动化测试（模拟跨作息边界场景）

**验收说明:** 本工单交付后，后续引导 / 宠物 / 打卡工单都能在其上读写数据。
