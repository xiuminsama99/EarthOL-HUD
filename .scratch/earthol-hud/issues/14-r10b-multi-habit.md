# 14: R10b-2 多习惯（1 主线 + 2 支线）

**What to build:** 破除单习惯限制——四视角体验官全票指出"只能养一个习惯是最大的结构性限制"（建完第一个就再也找不到新建入口，加第二个必须先删第一个；换习惯=总量缩水）。支持 1 个主线 + 最多 2 个支线习惯。

**Status:** done (R10b-2 已落地，277/277 测试全绿)

## 设计决策（拍板）

- **容量**：最多 3 个习惯（1 主线 + 2 支线）；主线保留养成线/一年之约全能力；支线同样用引擎全能力（各自独立养成线/目标/进度），只是 UI 层级低一档
- **数据**：需确认现有 EarthData 存储结构（疑似 habits 已数组化，主界面只取 [0]——若如此主要改 UI 层；若仍单习惯字段则做迁移 habits[0]）
- **主界面布局**：
  - 主线习惯 = 完整卡片（现状不动：目标大字/快捷按钮/输入/休息/最低版本）
  - 支线习惯 = 折叠卡片（显示：名字/今日目标/达标状态/「打卡」按钮），点开可看到同款快捷/输入/休息/最低版本
- **一键打卡**：底部大按钮 = 主线达标（保持 10 秒日常承诺）；支线在卡片内打卡
- **新建入口**：习惯区底部「＋ 再加一个习惯（最多 3 个）」，到 3 个后隐去；CreateHabitForm 复用（新建按钮在设置/习惯区）
- **仪表盘汇总**：行动天数/累计总量/最近 7 天行动率 = 全部习惯合并口径（行动天数=任意习惯有活动的天数；总量=合计；行动率=任意达标）；一年之约面板 = 主线（支线不叠加，避免数字爆炸）；热力图 = 任意习惯当天最佳结果
- **删除**：支线可单独删除（确认弹窗）；主线删除后自动提升第一个支线为主线（或提示重建；选前者——不丢用户已有数据）
- **迁移**：旧数据单习惯 → habits[0] 主线；「习惯已删除，可以建立新的习惯了」文案废弃
- **打卡语**：buildAutoNote 按当前打卡的习惯名生成（已支持）；一键打卡固定主线
