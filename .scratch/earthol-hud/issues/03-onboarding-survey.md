# 03: 引导问卷与身份设定

**What to build:** 新用户进入 App 的完整引导链路：欢迎页（「人生是游戏」心智）→ 用几句大白话输入反愿景（最怕自己变成什么样）→ 正愿景/身份宣言（想成为什么样的人）→ 描述最想改掉的一个坏习惯或想养成的第一个好习惯。系统根据描述展示两张对比图（现状版 vs 向往版）；AI 生成图不在范围，用模板图/占位图兜底。愿景文本持久化，老用户跳过引导直接进主界面。

**Blocked by:** 02（时间锚点 + 数据模型 + 登录地基）

**Status:** ready-for-agent

- [ ] 新用户打开 App 看到「欢迎进入地球online玩家控制台」引导界面，立刻进入「人生是游戏」的心智
- [ ] 用户用大白话输入反愿景与正愿景，不用填表格
- [ ] 用户可描述「我现在最想改掉的一个坏习惯」或「想养成的第一个好习惯」
- [ ] 系统展示现状版 vs 向往版两张对比图；AI 图不可用时回退到模板图/占位图
- [ ] 愿景文本与回答持久化，再次打开仍可见、可回看
- [ ] 已完成引导的老用户跳过引导直接进入主界面
- [ ] 引导数据写入用户档案，供后续习惯链路与天平可视化读取
