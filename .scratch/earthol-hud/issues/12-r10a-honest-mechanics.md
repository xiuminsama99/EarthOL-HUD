# 12: R10a 机制兑现轮（四视角体检产出）

**What to build:** 兑现"不惩罚、不虚假成功"产品哲学——引擎机制与文案对齐。四视角体验官全票指出：21 天养成线=换名字的 streak（20/21 漏一天=归零），与"漏一天没关系"矛盾；超额清零养成却文案说"不计入"；休息券只能靠超额获得（经济死循环）；戒除习惯永远养不成；365 累计=今日量×365 假数字；达成率 100% 不含漏卡。

**Status:** ready-for-agent

## 一、规则改动（引擎，最高优先）

### R-1 养成线改窗口制
- 现规则：formationDays 连续达标计数，达标日 +1，未达标/超额/缺勤归零，≥21 = 已养成
- 新规则：**21 天滑动窗口内累计达标天数 ≥14 = 养成成功**（isFormed），窗口内达标日 +1、未达标/超额日**冻结不加天也不清零**、缺勤只清窗口外的旧天数（保持总进度感知）
- 具体实现建议：`HabitState` 增加 `recentStats`（近 21 天的每日结果数组，或达标日/缺勤日计数），formationDays 改为"当前窗口内达标天数"
- 保留既有字段兼容迁移（旧数据 formationDays 直接映射为窗口计数）
- UI 文案："养成进度 X/21"→"21 天里已达标 X 天（≥14 天即养成）"；缺勤提示改"缺勤的一天不计入，之前的天数都保留——没关系，继续就是"
- 未达标/超额：不再清零，文案"今天没达到目标，进度冻结一天——之前 X 天保留"
- 缺勤 ≥3 天（含）：仍触发目标回退机制（保留），但养成进度**不归零**，只冻结
- **"已养成 ✓"不再丢**：养成成功后 21 天窗口只做刷新，不再被单个未达标/超额/缺勤撤销（后续连续 7 天未行动才进入"待巩固"提示）

### R-2 休息券经济修复
- 新增获取途径：**连续达标 7 天 = 赠 1 张休息券**（达成日当天发放，文案"连续达标 7 天，获得 1 张休息券"）
- 超额语义改名："多做了 N（不建议）"→「**储蓄日**：多做一点，存一张休息券」；不再"不建议"
- 超额当天：只冻结不加养成天（同 R-1），不再清零
- 券上限不变（=当日目标量）

### R-3 戒除习惯适配养成线
- 戒除（反向）习惯：目标触底 0 当天 = **完成戒除 = 直接已养成 ✓**（养成线对戒除类完成=成功）
- 完成态入口：目标 0 后提供「继续坚持（今天也没做 X）」打卡模式，记录复吸回归；"做 1 个就算数"按钮对戒除隐藏
- 养成进度展示：戒除习惯改为"戒除天数"（连续未复吸天数）

### R-4 数字诚实化
- **365 累计**：改为真实等差累计——以当前目标与每日递增规则计算"以现在的节奏，明年今天你会做到 X"（等差数列求和的全年量），或明确标注"按今天这个量算"。选清晰诚实的方案：`以现在的节奏，一年后你会完成 X 个（累计）`
- **目标达成率**：分母 = 应有打卡天数（含缺勤日），改名"打卡率"；或改"最近 7 天行动率"（选后者更简单直观，作为默认展示）
- **明日目标预告**：打卡后不显示"今日目标跳变"，改显示"今日已达成 ✓ · **明日目标 X**"（基于当前状态的真实值）
- **稳定天数 vs 养成进度**：卡片合并或改名（"达标次数"与"21 天达标进度"），同屏不打架——达标次数=累计达标日数（只增），养成进度=当前窗口达标数
