## P0 真 bug（4/4 或 3/4 视角独立抓到）

### BUG-1 休息券通胀（游戏设计师+难民+老用户）
- 现象：连续达标数用 21 天窗口裁剪后的 formationDateList 数，`21 % 7 === 0` 恒成立 → 窗口满 21 天后每天白送 1 券（60 天=42 券）
- 修复：使用**未被窗口裁剪的原始连续达标计数**（新增 streakDays 独立累计，缺勤/未达标/超额重置，达标 +1），`streakDays % 7 === 0` 时赠券；不改窗口制语义
- 补测试：day21 后不再每日赠券 / 断一次连胜重计 / day63 应只有 9 张而非 42 张

### BUG-2 「我的故事」假删除（4/4 抓到）
- 现象：确认框说"之后可以重新打卡"，删除后状态不回滚（totalAmount/actionCount/养成/券照旧），且重打被拒 already-checked-in
- 修复（二选一，选对用户最诚实）：**删除当天记录 = 完整撤销当天**（回滚引擎状态：lastCheckinDate/actionCount/totalAmount/formationDateList/当日券增减/达成率条目）——删除后真的可以重新打卡；若回滚复杂度高，则把文案改为"只删除文字记录，今天的打卡状态保留"且删除后按钮禁用（二选一，实现时评估，优先完整回滚）
- 补测试：删除后重新打卡成功 / 状态确实回滚 / 历史记录只读

### BUG-3 漏卡回归目标跳崖（游戏设计师+老用户）
- 现象：回归日预告"明日 6"，打卡瞬间目标 +3~+5 弹回 11（回退折扣打卡即失效）
- 修复：两种（选一）：① 回退梯度保留——打卡后回退不立即弹回，按每缺勤日的"回归补偿"分步回升；② 诚实预告——打卡后明日目标如实显示，且预告行标注"逐日回升中"。选 ① 更符合"不惩罚"（难度回归平缓），实现需改引擎回退逻辑 + 测试（漏 3 天回归后目标 = 基准+步数-漏天数，之后每天只回升 1 步直到原位，且预告准确）

## P1 闭环（3/4 视角）

### P1-1 戒除完成态死胡同
- "继续坚持"按钮（记录"今天也没做 X"，每日保持态）——完成态下唯一按钮（移除"做 1 个就算数"——语义错位；「休息」保留还是移除可选）
- 复吸记录：继续坚持态下做了 X → 记录一次复吸（故事线有标记），目标从 0 重新走戒除（温和：不惩罚，只是重新开始）
- 测试：完成态入口 / 继续坚持打卡 / 复吸记录

### P1-2 休息券价值化（价值审查员："废币被支配"）
- 免费保底 "做 1 个就算数" 与 "休息" 全面等价且免券 → 差异化：**休息 = 用券换"明天目标不变 + 今日不计入行动率分母"**；保底 = 免券但今日计入行动率分母（会拉低行动率）。或者在设置/引导中给两按钮各 1 句明确差异说明
- 实现从简：界面差异说明（人话）+ 若引擎已支持则保持；限制：不做大重构
- 发券零提示：赠券日反馈加"连续达标 7 天，获得 1 张休息券"
