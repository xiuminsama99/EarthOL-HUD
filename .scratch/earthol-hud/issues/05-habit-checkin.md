# 05: 单个习惯的等差数列打卡

**What to build:** 核心打卡链路：用户从引导选定的坏/好习惯建立第一个习惯（设定方向——养成/戒除——与起始基准；AI 自动拆解后置，MVP 手动设定即可）；系统按微习惯引擎算出的当日目标量展示与打卡；用户到自认上限时通过动态调节条把习惯量「定死」；单日超额被劝阻并积累假期币；漏卡不惩罚、额度动态回退但不归零。习惯与打卡记录云端持久化、多设备一致。

**Blocked by:** 01（微习惯引擎领域核心）、02（时间锚点 + 数据模型 + 登录地基）

**Status:** ready-for-agent

- [ ] 用户可建立一个习惯，设定方向（养成/戒除）与起始基准
- [ ] 系统按等差数列显示今日目标量：每天只多做一个（或只多减一点）
- [ ] 用户完成当日目标量并打卡，系统记录完成量与一句话记录
- [ ] 用户可把习惯量「定死」（锁死自认上限），之后每天目标量不再变化
- [ ] 单日超额收到「不建议，离目标更远」提示，超额量存为假期币
- [ ] 漏卡不惩罚、不补练、不归零：重新归来时额度动态回退但不越过起点
- [ ] 习惯与打卡记录云端同步，多设备一致
- [ ] 打卡数据来自微习惯引擎（唯一测试接缝），UI 不承载领域逻辑

**验收说明:** 本工单的数据来源与规则判定全部走 01 的引擎，不做第二套实现。
